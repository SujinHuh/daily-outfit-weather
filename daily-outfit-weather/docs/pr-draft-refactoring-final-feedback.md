## 🔍 변경 내용 요약  

- **(예정) 질문 생성과 최종 피드백 생성 트리거 분리**: `generateNextQuestion` 내부에서 수행하던 질문 생성 로직과 최종 피드백 생성 역할을 가시적인 도메인 책임 단위로 분리합니다.
- **(예정) `FinalFeedbackService` 도입**: 최종 피드백 생성 및 저장을 전담하는 별도 서비스 클래스를 추출하여 책임 구조를 개선합니다.
- **(배경)**: 2/3번째 질문 흐름 테스트 작성 중 `InterviewServiceImpl` 클래스가 단일 책임 원칙(SRP)을 위배하고 있으며, private 메서드로 얽혀 있어 단위 테스트 확장에 제약이 발생함을 확인했습니다.

## ❓ 변경 이유  

- **(문제 발견)**: `InterviewServiceImpl`이 다음 질문 생성뿐만 아니라 인터뷰 완료 시의 최종 피드백 생성/저장까지 담당하여 책임 경계가 불명확했습니다.
