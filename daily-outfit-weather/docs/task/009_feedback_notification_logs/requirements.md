# Requirements: 009 Feedback and Notification Logs

Phase 8 목표: 추천 피드백과 알림 로그를 저장한다.

## 기능 요구사항

- [x] 추천 결과에 대한 온도/우산 피드백을 저장한다.
- [x] 같은 추천에 다시 피드백을 남기면 기존 피드백을 갱신한다.
- [x] 다른 사용자의 추천에는 피드백을 남길 수 없다.
- [x] 알림 시간이 지난 사용자 중 알림 옵션이 꺼져 있지 않은 사용자의 알림 로그를 생성한다.
- [x] 실제 푸시 발송 없이 `PENDING` 상태 로그만 저장한다.
- [x] 사용자 본인의 알림 로그와 오늘 알림 로그를 조회할 수 있다.

## 비기능 요구사항

- 피드백과 알림 로그는 Flyway 마이그레이션으로 관리한다.
- 세션 인증 사용자의 소유권을 서비스 계층에서 검증한다.
- 운영 배포 전 CSRF/CORS/cookie 정책을 확정한다.
