# Requirements: 010 PWA Setup

## 목적
- 사용자가 모바일 기기에서 앱처럼 설치하고 사용할 수 있는 환경 제공 (PWA)
- 오프라인 상태에서도 기본적인 앱 쉘을 로드할 수 있도록 설정

## 요구사항
1. **PWA Manifest 설정**
   - 앱 이름: `오늘 뭐입지?`
   - 짧은 이름: `오늘뭐입지`
   - 테마 컬러: 서비스 기본 컬러 (예: `#ffffff`)
   - 아이콘: 192x192, 512x512 해상도 아이콘 포함 (기존 favicon 활용 또는 대체)

2. **서비스 워커 설정**
   - `vite-plugin-pwa`를 사용하여 서비스 워커 생성 및 등록
   - 기본 정적 자산(JS, CSS, HTML, Icons) 캐싱 설정

3. **설치 지원**
   - 브라우저의 '홈 화면에 추가' 제안이 동작하도록 필수 조건 충족

4. **모바일 최적화 확인**
   - iOS/Android 등에서 주소창 없이 앱처럼 실행되는지 확인을 위한 메타 태그 추가
