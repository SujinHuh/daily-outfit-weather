# Requirements: 006 Location Grid Mapping

## 목표

- 온보딩/프로필 저장 시 위치 입력값을 기상청 격자 좌표 `nx`, `ny`로 자동 보강한다.
- 사용자가 위치를 검색할 수 있도록 정적 위치 검색 API를 제공한다.
- 좌표가 직접 전달된 경우에는 사용자 입력 좌표를 우선 사용한다.

## 범위

- 정적 KMA 격자 좌표 catalog
- `GET /api/locations/search?keyword=`
- 프로필 저장/수정 시 좌표 자동 보강
- 좌표 매핑 단위 테스트와 프로필 통합 테스트

## 비범위

- 전국 전체 행정동 데이터 구축
- 외부 주소/지도 API 연동
- 현재 위치 자동 감지
