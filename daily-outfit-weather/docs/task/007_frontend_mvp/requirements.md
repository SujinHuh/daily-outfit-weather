# Requirements: 007 Frontend MVP

## 목표

- 사용자가 온보딩 정보를 입력하고 오늘 추천 결과를 확인할 수 있다.
- 위치 검색 API를 이용해 집/직장 위치를 선택할 수 있다.
- 설정 화면에서 온보딩 정보를 수정할 수 있다.

## 범위

- React/Vite 단일 페이지 앱
- 온보딩 화면
- 오늘 추천 화면
- 설정 변경 화면
- 위치 검색 UI
- 피드백 UI 골격
- 백엔드 API proxy 연결

## 비범위

- Google OAuth 로그인
- 실제 피드백 저장 API 연결
- 푸시 알림 설정 상세 화면
