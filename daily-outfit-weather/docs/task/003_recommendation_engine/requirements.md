# Requirements: 003 Recommendation Engine

## 기능 요구사항

- 출근/퇴근 날씨 snapshot과 사용자 민감도, 이동수단, 말투를 입력으로 받는다.
- 체감온도, 강풍, 추위/더위 민감도, 이동수단, 퇴근길 기온 하락을 반영해 추천 기준 온도를 계산한다.
- 추천 기준 온도에 따라 상의/외투 추천이 달라져야 한다.
- 강수확률 또는 강수유형에 따라 우산/눈길 준비물 추천이 달라져야 한다.
- 말투 설정에 따라 추천 문구가 달라져야 한다.

## 품질 요구사항

- Phase 3 엔진은 DB와 외부 API에 의존하지 않는 순수 룰 컴포넌트로 유지한다.
- Phase 4에서 서비스/API/저장 로직과 연결할 수 있도록 결과 DTO를 반환한다.

## 검증 요구사항

- 체감온도별 추천 차이를 단위 테스트로 검증한다.
- 강수/눈/강풍 준비물 추천을 단위 테스트로 검증한다.
- 말투별 문구 차이를 단위 테스트로 검증한다.
