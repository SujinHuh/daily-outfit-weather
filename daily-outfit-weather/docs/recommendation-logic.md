# Recommendation Logic

룰 기반 옷차림 추천 로직 설계 문서입니다.

## 추천 기준 데이터

1차 구현에서 사용하는 데이터:

- 기온
- 체감온도
- 최저기온
- 최고기온
- 일교차
- 강수확률
- 강수 시간대
- 풍속
- 출근 시간대 날씨
- 퇴근 시간대 날씨
- 추위 민감도
- 더위 민감도
- 이동수단

후순위 데이터:

- 미세먼지
- 자외선
- 컨디션
- 생리주기
- 피드백 기반 개인화 보정값

## 기본 추천 흐름

1. 사용자 프로필 조회
2. 집/직장 위치 조회
3. 출근/퇴근 시간 기준 날씨 조회
4. 날씨 조건 분석
5. 사용자 민감도 반영
6. 최종 체감 기준 온도 계산
7. 옷차림 추천 생성
8. 준비물 추천 생성
9. 추천 이유 생성
10. 추천 결과 저장

## 체감 기준 온도 보정

예시:

```text
기본 체감온도: 15도
바람 강함: -2도
추위를 많이 탐: -2도
도보 이동: -1도
퇴근길 기온 하락: -1도
최종 추천 기준 온도: 10도
```

## 옷차림 추천 기준

| 기준 체감온도 | 추천 |
| --- | --- |
| 28도 이상 | 반팔, 얇은 하의 |
| 23~27도 | 반팔 또는 얇은 셔츠 |
| 20~22도 | 얇은 긴팔, 셔츠 |
| 17~19도 | 얇은 니트, 가디건 |
| 12~16도 | 니트, 바람막이, 자켓 |
| 8~11도 | 코트, 두꺼운 가디건 |
| 4~7도 | 패딩 또는 두꺼운 코트 |
| 3도 이하 | 두꺼운 패딩, 목도리, 장갑 |

## 준비물 추천 기준

| 조건 | 추천 준비물 |
| --- | --- |
| 강수확률 60% 이상 | 우산 |
| 퇴근 시간 비 예보 | 작은 우산 |
| 눈 예보 | 미끄럼 주의 신발 |
| 풍속 강함 | 바람막이 |

후순위:

| 조건 | 추천 준비물 |
| --- | --- |
| 미세먼지 나쁨 이상 | 마스크 |
| 자외선 높음 | 선크림/모자 |

## 추천 문구 예시

캐릭터형:

```text
오늘은 바람이 꽤 불어요!
얇은 니트에 바람막이를 챙기면 딱 좋아요.
퇴근길에는 비가 올 수 있으니 작은 우산도 챙겨주세요~
```

추천형:

```text
오늘은 출근길보다 퇴근길이 더 쌀쌀해요.
얇은 외투를 챙기는 게 좋아요.
```

정보형:

```text
퇴근 시간대 체감온도가 낮아질 것으로 예상됩니다.
얇은 외투 착용을 권장합니다.
```

## 클래스 구조

```text
recommendation
 ├── RecommendationController
 ├── RecommendationService
 ├── RecommendationRuleEngine
 ├── WeatherConditionAnalyzer
 ├── OutfitSelector
 ├── ItemSelector
 ├── RecommendationMessageGenerator
 └── dto
```

## 책임 분리

`RecommendationService`:

- 사용자 프로필 조회
- 날씨 데이터 조회
- 추천 엔진 호출
- 추천 결과 저장
- 응답 DTO 생성

`RecommendationRuleEngine`:

- 날씨 조건과 사용자 설정을 기반으로 추천 기준 온도 계산
- 외투 필요 여부 판단
- 우산 필요 여부 판단
- 강풍 여부 판단

`RecommendationMessageGenerator`:

- 사용자의 말투 설정에 따라 추천 문구 생성
- 정보형/추천형/캐릭터형 문구 분리
