# KMA Location Grid Service Area

## Current Readiness

The KMA grid catalog has been expanded from an MVP allowlist to a generated nationwide administrative-dong catalog.

Current catalog:

- File: `backend/src/main/resources/location/kma_location_grids.csv`
- Row count: 3,495 locations, excluding the CSV header
- Columns: `sido,sigungu,dong,nx,ny`
- Coverage: 17 Korean sido GeoJSON files from the generation source

The catalog is used by:

- `GET /api/locations/search?keyword=`
- profile create/update location enrichment
- weather recommendation calls that need KMA `nx`/`ny`

## Generation Source

The CSV is generated by:

```bash
node scripts/generate-kma-location-grids.mjs
```

The script fetches 17 administrative-dong GeoJSON files from:

```text
https://github.com/raqoon886/Local_HangJeongDong
```

For each feature, it:

1. reads `sidonm`, `sggnm`, and `adm_nm`
2. calculates an approximate polygon centroid
3. converts the centroid latitude/longitude to KMA DFS grid `nx`/`ny`
4. writes `backend/src/main/resources/location/kma_location_grids.csv`

The repository currently does not expose an explicit license in GitHub metadata. Treat this as a data-source review item before public production launch, or replace the source with an approved official/public dataset.

## Runtime Behavior

- `GET /api/locations/search?keyword=` returns matches from the static generated catalog.
- Search normalizes whitespace and supports sido, sigungu, dong, and combined full names.
- Search also supports common base-dong aliases:
  - `성내동` can match `성내1동`, `성내2동`, `성내3동`
  - `잠실동` can match `잠실본동`, `잠실2동`, `잠실3동`, etc.
- Profile create/update preserves caller-provided `nx`/`ny` when both values are present.
- If `nx`/`ny` are omitted and `sido`/`sigungu`/`dong` match the catalog, the profile service fills the grid values.
- If a location is not in the catalog and no explicit `nx`/`ny` are supplied, grid values remain null.

## Remaining Risk

- KMA grid coordinates are generated from administrative polygon centroids, not copied from an official KMA per-dong grid table.
- Some generated centroids can differ from a municipality's preferred representative weather point, especially for large 읍/면 areas, islands, or irregular boundaries.
- Before public production launch, validate high-traffic target regions against an approved KMA grid source or live KMA weather responses.
- If an approved nationwide KMA grid table becomes available, regenerate the CSV from that source instead of centroid conversion.
