# Product Requirements

`오늘 뭐입지?`의 제품 요구사항을 정리한 문서입니다. 원본 기획 문서는 `docs/project-brief.md`에 보존되어 있으며, 실제 구현 기준은 이 문서와 `docs/development-plan.md`를 우선합니다.

## 서비스 정의

> 오늘 날씨를 알려주는 앱이 아니라, 오늘 내가 춥지 않게 나갈 수 있도록 옷차림을 결정해주는 앱

## 문제 정의

기존 날씨 앱은 기온, 강수확률, 풍속 같은 정보를 제공하지만 사용자는 다음 판단을 직접 해야 합니다.

- 오늘 겉옷을 챙겨야 하는가
- 우산을 가져가야 하는가
- 출근길은 괜찮지만 퇴근길에는 추워지지 않는가
- 바람 때문에 실제보다 더 춥게 느껴지지 않는가
- 개인의 추위/더위 민감도와 일반 추천이 맞는가

## MVP 목표

사용자가 매일 아침 앱을 열었을 때, 출근길과 퇴근길 날씨를 바탕으로 오늘 입을 옷과 챙길 물건을 5초 안에 결정할 수 있게 합니다.

## 핵심 사용자

1차 사용자:

- 출근 전 매일 날씨와 옷차림을 고민하는 직장인
- 겉옷과 우산 여부를 자주 고민하는 사용자
- 출근길과 퇴근길 날씨 차이 때문에 옷차림을 고민하는 사용자
- 추위/더위 민감도가 일반적인 추천과 잘 맞지 않는 사용자

2차 사용자:

- 복잡한 날씨 정보를 보기 어려운 사용자
- "오늘 외투 챙겨", "우산 챙겨"처럼 간단한 안내를 원하는 사용자
- 가족에게 오늘 옷차림을 알려주고 싶은 사용자

## 핵심 가치

### 사용자의 판단 비용을 줄인다

사용자가 기온, 체감온도, 강수확률, 퇴근 시간 날씨를 직접 조합하지 않아도 되게 합니다.

```text
앱 확인
→ 오늘 추천 확인
→ 옷차림 결정
```

### 출근/퇴근 시간을 함께 고려한다

아침 날씨만 보지 않고 다음 정보를 함께 고려합니다.

- 현재 날씨
- 출근 시간대 날씨
- 퇴근 시간대 날씨
- 일교차
- 강수 시간대
- 바람

미세먼지와 자외선은 원본 아이디어에는 포함되어 있으나 1차 구현에서는 실제 API 연동 대상에서 제외합니다.

### 개인 민감도를 반영한다

MVP에서는 간단한 설정값으로 반영합니다.

- 추위 민감도
- 더위 민감도
- 이동수단
- 출근 시간
- 퇴근 시간

피드백 기반 개인화는 후순위 기능으로 둡니다.

## MVP 최종 포함 기능

- Google OAuth 로그인
- 사용자 기본 프로필 저장
- 집/직장 위치 등록
- 동 단위 위치 검색 또는 입력
- 출근 시간 설정
- 퇴근 시간 설정
- 알림 시간 설정
- 추위/더위 민감도 설정
- 이동수단 설정
- 기상청 단기예보 API 연동
- 오늘 날씨 조회
- 출근/퇴근 시간대 날씨 분석
- 룰 기반 옷차림 추천
- 준비물 추천
- 오늘 추천 결과 저장
- 오늘 추천 화면 제공
- 추천 피드백 등록
- 알림 발송 대상 생성
- 알림 로그 저장
- 날씨/옷차림 유형별 고정 이미지 표시

## MVP 제외 범위

- 실제 웹 푸시 발송
- FCM 연동
- 미세먼지/자외선 실제 API 연동
- 생리주기 반영
- 가족 프로필
- 옷장 등록
- AI 추천
- 캐릭터 커스터마이징
- 지도 기반 위치 선택
- 현재 위치 자동 감지
- 결제/구독
- 앱스토어/플레이스토어 배포

## 사용자 입력 정보

필수 입력:

| 항목 | 설명 |
| --- | --- |
| 닉네임 | 사용자 표시명 |
| 집 위치 | 동 단위 입력 |
| 직장 위치 | 동 단위 입력 |
| 출근 시간 | 출근길 날씨 기준 |
| 퇴근 시간 | 퇴근길 날씨 기준 |
| 알림 시간 | 아침 정기 알림 기준 |
| 추위 민감도 | 추위를 많이 타는지 |
| 더위 민감도 | 더위를 많이 타는지 |
| 이동수단 | 도보/대중교통/자차 등 |

선택 입력:

| 항목 | 설명 |
| --- | --- |
| 말투 설정 | 정보형/추천형/캐릭터형 |
| 변경 알림 설정 | 중요할 때만/비·눈만/받지 않기 |
| 컨디션 | 2차 기능 |
| 생리주기 | 2차 기능 |
| 가족 프로필 | 2차 기능 |

`변경 알림 설정`은 MVP 1차에서 설정값 저장까지만 허용합니다. 실제 날씨 변경 감지와 푸시 발송은 MVP 1.5 또는 2차 기능입니다.

## 말투 설정

MVP 기본값은 캐릭터형입니다.

정보형:

```text
오늘은 체감온도가 낮아 얇은 외투를 권장합니다.
```

추천형:

```text
오늘은 생각보다 쌀쌀해서 얇은 외투 하나 챙기는 게 좋아요.
```

캐릭터형:

```text
오늘 바람이 꽤 불어요! 바람막이 챙기면 딱 좋아요.
```
